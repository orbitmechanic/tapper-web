# TAPPER: LAST CALL — web build

This repository is the GitHub Pages deployment of
[orbitmechanic/tapper](https://github.com/orbitmechanic/tapper), a 2D arcade
bartending game written in Rust with Bevy 0.20.1.

**Play:** <https://orbitmechanic.github.io/tapper-web/>

The files here are generated by `tools/build_web.sh` in the source repository.
Do not edit the built JavaScript or WASM by hand. Original pixel art, music and
sound effects are generated in the source repo with Krita and Python.

Source, tests, art pipeline and Linux builds:
<https://github.com/orbitmechanic/tapper>

MIT licensed. An unlicensed, affectionate homage to the 1983 arcade game
*Tapper*; not affiliated with its rights holders.
